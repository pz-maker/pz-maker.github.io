# The Pragmatic Programmer

> 读书目的：学英语。读原版技术书，生词随手记，顺便吸收书里的工程建议。

## 简单记几笔

### 2026.8.4

An investment in knowledge always pays the best interest.

The early bird might get the worm, but what happens to the early worm?

| 生词 | 释义 |
| --- | --- |
| obsolete | 过时的：This kind of technology has become obsolete. / 淘汰：Many old customs have been obsoleted. |
| portfolio | 文件夹；公事包 |
| periodically | 周期性地 |
| voraciously | 如饥似渴地 |
| media hype | 媒体炒作（create media hype = 制造媒体炒作） |
| zealots | 狂热者 |
| prominently | 显著地 |
| cynical | 愤世嫉俗的；怀疑一切的 |
| sterile | 无菌的，不接地气的，无创造性的 |
| orphan | 孤儿，无依无靠的 |
| laptop | 笔记本，便携式计算机 |

## 书中的建议

1. Learn at least one new language every year.
2. Read a technical book each month.
3. Read nontechnical books, too.
4. Take classes.
5. Participate in local user groups and meetups.
6. Experiment with different environments. (windows/linux)
7. Stay current.
