软件开发初探

AI时代的软件开发，不仅意味着敲代码，还意味着环境，规范，安全，项目管理

1.环境

在使用Agent时，先检查开发环境，若无开发环境，则安装并配置，需要区分：

  • 已安装并可用；
  • 已安装但版本不合适；
  • 未安装；
  • 无法验证;

2.规范

如： 固定技术栈（可以先给需求，再反推技术栈）

3.安全

如： 不给页面不必要的本地系统权限； 不接入API； 不添加数据库； 不写入任何密钥； 不擅自更换技术栈。

4.项目管理

熟练掌握git命令：

git init开始管理

git log –oneline –all 查看项目主干进程

管理方法：先在分支上改动，若满意则拉回主干，不满意回退原始状态 1.git checkout -b dev(dev只是分支名称) 从当前主干中进入分支 2.写代码 3.git status (还没有commit时查看有哪些改动) 4.若写崩了： git restore git clean -fd 若满意： git add . git commit -m “本次改动的名称” git switch master git merge dev (注：移除分支) 5.回看状态 git log –oneline –all 完毕

我的第一个桌宠

德国突击兵Q版桌宠，名字叫做盔仔 / Helmchen

盔仔可爱捏

可以和盔仔对话

已实现功能：

  • 桌面快捷键
  • 单击：受惊反应 + 随机双语台词
  • 双击：打开人设卡
  • 拖动：把盔仔挪到任意位置
  • 右键：人设卡 / 退出桌宠

后续计划

  • 增加“设置”，可以自定义API接口，以及其它的各种功能的开关
  • 删除文件时，盔仔押送文件图标到回收站
  • 打开浏览器，盔仔会站在浏览器边缘，假装审查内容，视频播放时会歪头
  • 每过特定时间，盔仔会变着法子提醒你休息
  • 增加专注模式，此时盔仔头上会出现计时器，退出时用战报的形式报告日期（德语），时长，键盘敲击次数，评语（双语，AI现写最好）
  • 待机动画：站岗，检修，吃面包等
  • 对话框加入语音功能

总结

深入挖掘，桌宠也有很多好玩的地方

AI时代创意和审美也很重要，而不仅仅是技术

了解计算机相关知识才能更好地与AI进行协作，筛选优质信息

项目越大，越难管理。所以一定需要协议和规范
