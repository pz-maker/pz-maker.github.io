AI Infra 学习路线总览

方法论参照《学习变现》：知识地图（本篇）→ 学习路线图（四阶段页）→ 关键词便签 → 学习日志。 知识地图回答"学什么"（书单节点 + 阅读范围 + 深度要求），学习路线图回答"怎么学"（有截止时间、有学习顺序、有意识输出）。

四阶段全景

阶段 时间跨度 Deadline 主题 入口
阶段一 0 ~ 3 个月 2026-11-12 基础工程筑基（CS:APP / Linux / 算法 / DDIA） 阶段一
阶段二 3 ~ 6 个月 2027-02-12 AI 工程入门（PyTorch / LLM / MLOps / 云原生） 阶段二
阶段三 6 ~ 12 个月 2027-08-12 系统能力进阶（分布式训练 / CUDA / 性能 / 推理） 阶段三
阶段四 12 ~ 18 个月 2028-02-12 平台架构与前沿（K8s / 架构 / 论文 / 国产芯片） 阶段四

每日 / 每周学习节奏

时间段 安排
工作日早 1h 刷题 / 读论文
工作日晚 2h 精读教材 + 做笔记
周末全天 实战项目 / Lab / 源码阅读
每周末 复盘本周学习，调整下周计划
每月末 写一篇技术博客，检验输出能力

关键原则

  1. 先广度后深度：阶段一、二建立全景认知，阶段三、四在特定方向深耕。
  2. 代码为王：每读完一章，必须有对应的代码实践，否则等于没读。
  3. 输出倒逼输入：每学完一个模块，写一篇博客或做一次分享，检验真理解。
  4. 论文是最终教材：书籍建立框架，论文填充细节，源码验证假设。
  5. Deadline 是铁的纪律：每个阶段的 Deadline 不可延期，到期即验收。
