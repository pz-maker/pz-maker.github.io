# AI Infra Wiki · 发布指南

> 从 Obsidian 写笔记到网站上线，全程 2 步。本文件随仓库同步，放在 vault 内随时可查。

## 工作流总览

```
Obsidian 写作 ──▶ Ctrl+Shift+S 一键推送 ──▶ GitHub Actions 自动构建 ──▶ pz-maker.github.io
   （2 步）              （快捷键）                （无需操作）                （自动上线）
```

## 两步发布

1. **写作**：在 `site/content/posts/` 目录下 `Ctrl+N` 新建笔记，直接输入标题回车
   - Templater 文件夹模板自动套用：自动创建 `site/content/posts/<标题>/index.md`（leaf bundle 结构）
   - frontmatter（标题/日期/分类）已自动填好：分类默认「学习路径」，`description` 留空即可（卡片自动截取正文摘要）
   - 在 `site/content/posts/weekly/` 下新建 = 周记模板（自动算 ISO 周号、写 `issue` 编号）
2. **发布**：`Ctrl+Shift+S` 一键提交并推送，等待约 1 分钟即可在网站上看到

## 一次性设置（新机器）

### Obsidian 插件（社区市场安装）
| 插件 | 用途 | 关键设置 |
| --- | --- | --- |
| Templater | 新文章/新周记模板 | 模板文件夹 = `site/_templates`；文件夹模板已配好（posts/ 下新建自动套用） |
| Obsidian Git | 一键提交推送 | 快捷键 `Ctrl+Shift+S`（obsidian-git:commit-and-sync）已绑定；建议手动提交 |

### Obsidian 核心设置
- 设置 → 文件与链接 → 附件默认存放路径 = **当前文件所在文件夹**
- 设置 → 编辑器 → 默认编辑模式 = Markdown

## 目录与约定

| 路径 | 说明 |
| --- | --- |
| `site/content/posts/<slug>/index.md` | 文章（每篇一个文件夹，附件同目录） |
| `site/content/posts/weekly/` | 周记（`_index.md` + 每篇带 `issue` 编号） |
| `site/content/about.md` `links.md` | 关于 / 友链 |
| `site/content/moments/` | 动态（仅 date frontmatter，按日期排序） |

### frontmatter 必填字段
- `title` — 文章标题（模板自动填）
- `date` — 发布日期（模板自动填）
- `categories` — 中文分类，**首页知识星图按此分组**（模板默认「学习路径」，可选：学习路径 / 周记 / 精读 / 站点指南）
- `description` — 可选，留空则卡片自动从正文截取摘要

### Markdown 语法约定
| 写法 | 效果 |
| --- | --- |
| `<mark class="va-hl">重点</mark>` | 青蓝霓虹高亮（Obsidian 里显示为黄色高亮，写 mark 标签两头通吃） |
| `- [ ] 待办` / `- [x] 完成` | 任务列表（霓虹勾选样式） |
| `[文字](/posts/文章slug/)` | 站内链接（**不要写相对路径**） |
| `$$...$$` | LaTeX 公式（KaTeX 渲染） |
| `> 引言` | 引用块（首段会作为摘要来源） |

### 站内链接 / 星图
- 每篇文章与站内其他文章互链后，连线会自动出现在首页知识星图中
- 图片用相对路径（如 `![](diagram.png)`），与 index.md 同目录

## 疑难排查

- **网站没更新**：检查 GitHub Actions 是否成功（仓库 → Actions 页），失败时查看日志
- **图片不显示**：确认图片与 `index.md` 同目录，且路径是相对路径
- **星图节点缺失**：确认文章有 `date` 字段且在 `posts/` 下
- **Obsidian 显示 index.md 重名**：正常，Obsidian 用文件名区分，建议开启"显示完整路径"
